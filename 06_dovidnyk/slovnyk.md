# Словник ключових розрізнень

[До навігації](../README.md)

**Статус: [М].** Це робочі визначення бібліотеки, а не твердження про єдине правильне вживання в усіх дисциплінах.

| Термін | Робоче значення | Не плутати з |
|---|---|---|
| Регуляція | Зміна процесів для підтримання або перебудови функціонування | Постійний комфорт, свідомий контроль |
| Гомеостаз | Підтримання певних параметрів у життєздатних межах | Незмінність усього організму |
| Алостаз | Регуляція через зміну режиму роботи відповідно до вимог | Універсальне пояснення всіх хвороб |
| Адаптація | Залежно від контексту: еволюційна ознака або пристосування протягом життя | Обов’язкова користь кожної реакції |
| Навчання | Відносно стійка зміна внаслідок досвіду | Будь-яка гостра зміна стану |
| Негативне підкріплення | Посилення поведінки через усунення неприємного наслідку | Покарання |
| Внутрішня модель | Стан системи, який у певному описі відображає важливі залежності | Обов’язково усвідомлена думка |
| Пластичність | Здатність змінювати організацію або функцію | Гарантоване поліпшення |
| Співрегуляція | Взаємний вплив учасників на їхній стан | Повна залежність або рівна відповідальність |
| Функціонування | Здатність діяти у важливих сферах життя | Лише низький бал симптомів |
| Когніція | Сімейство процесів використання інформації, пам’яті й навчання | Обов’язково людське мислення |
| Свідомий доступ | Доступність інформації для використання і, за відповідних умов, звіту | Автоматично повне пояснення переживання |
| Феноменальний досвід | Те, як переживається стан зсередини | Інтелект, успішність задачі |
| Самосвідомість | Різні форми усвідомлення себе | Необхідно кожний вид переживання |
| Нейронний корелят | Нейронна ознака, пов’язана зі станом | Доведена причина або достатня умова |
| Значущість | Релевантність події для організму або його цілей | Космічне призначення |
| Сенс | Зв’язок досвіду з цілями, цінностями й історією життя | Доведений задум Всесвіту |
| Цінність | Те, що вважається важливим або гідним дії | Будь-яка винагорода чи приємність |
| Причина | Чинник у поясненні виникнення події | Моральне виправдання |
| Біологічна функція | Роль ознаки, яку пояснюють в біологічному контексті | Свідомий намір природи |
| Гіпотеза | Перевірюване припущення | Вже встановлений факт |
| Операціоналізація | Перехід від поняття до процедури вимірювання | Вичерпне визначення природи явища |
| Медіатор | Передбачувана проміжна ланка ефекту | Доведений механізм лише через статистичний зв’язок |
| Модератор | Змінна, від якої залежить сила чи напрямок ефекту | Обов’язково причина самого розладу |
| Фізикалізм | Філософська позиція про фізичну природу реальності | Сам по собі повний механізм свідомості |
| Панпсихізм | Сімейство позицій про фундаментальність аспектів досвіду | Людські думки у кожного об’єкта |

У кожному дослідженні визначення потрібно конкретизувати. Наприклад, «контроль» може означати моторне гальмування, планування або право впливати на власне життя — це різні змінні.


## Психіка, допомога й редакційне вживання

Перенесено з окремого робочого словника 2026-11-10; тепер терміни зібрані в одному місці.

### Психіка

Сукупність процесів, завдяки яким живий організм сприймає, регулює, навчається, діє та взаємодіє. У людини до цього додаються мова, свідомість, особистість, культура й осмислення. Термін не означає автоматично наявність свідомого досвіду в будь-якої живої системи або нейромережі.

### Психічний стан

Конкретний, змінний у часі стан людини: рівень тривоги, збудження, втоми, настрою, уваги чи дезорієнтації. Стан не тотожний рисі особистості, діагнозу або моральній якості.

### Психологічне здоров’я

Функціональне й ціннісне поняття, яке в книзі означає можливість жити, діяти, підтримувати стосунки та відновлюватися в конкретних умовах без надмірного запобіжного страждання. Це не вимога постійного спокою, продуктивності чи однаковості.

### Психологічна проблема / труднощі

Опис повторюваного циклу переживань, дій, тілесних станів, стосунків або умов, який обмежує життя чи збільшує страждання. Термін не є діагнозом.

### Психічний розлад

Клінічна категорія, яку встановлюють у відповідному професійному контексті за діагностичними критеріями. У книзі не використовуємо цей термін як синонім будь-якої життєвої труднощі.

### Допомога

Будь-яка дія або взаємодія, яка має зменшити небезпеку, підтримати людину, розширити її можливості чи забезпечити доступ до відповідного ресурсу. Допомога може бути неформальною, соціальною, медичною або психотерапевтичною.

### Лікування

Професійне втручання, спрямоване на стан або захворювання, із визначеними показаннями, ризиками й оцінкою результату. Не називаємо слухання, освіту чи загальну підтримку лікуванням без відповідних підстав.

### Психотерапія

Організована професійна взаємодія, спрямована на зміни переживань, поведінки, стосунків або способу осмислення життя. Конкретний метод і його доказовість залежать від проблеми, групи та умов.

### Психіатрія

Медична галузь, яка оцінює психічні стани й розлади, ризики, тілесні фактори та можливість медикаментозного чи іншого медичного втручання.

### Сенс

Переживання зрозумілості, спрямованості та цінності життя або окремої дії. Сенс не тотожний доказу космічного задуму й не виправдовує шкоду.

### [Д], [Г], [М], [Ф]

[Д] — науково встановлене або прямо підтверджене джерелом у межах прочитаного матеріалу.

[Г] — гіпотеза, сценарій або твердження, яке потребує додаткової перевірки.

[М] — авторська робоча модель для організації пояснення; модель не є автоматично фактом.

[Ф] — філософське або ціннісне припущення про бажаний напрям дії.

Редактор перевіряє не лише окреме слово, а й те, чи не змінюється його статус непомітно в сусідньому абзаці.
